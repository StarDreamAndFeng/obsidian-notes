# 仓库目录地图与归类决策

依据根目录 `README.md` 的 MECE 规划，并标注 2026-09 仓库实际状态（实际状态优先）。

## 归类决策表

| 内容特征 | 归属目录 |
|---|---|
| 未写完、归属未定、临时素材 | `000-仓库管理/030-草稿` |
| 图片、PDF 等附件（不放正文） | `000-仓库管理/020-附件与资源` |
| 软件安装、环境搭建、命令踩坑、部署配置 | `500-资源整合/520-环境配置与部署` |
| 工具/软件/插件使用说明、方法论与工作流 | `500-资源整合/540-工具与软件` |
| 外部网页/知乎/公众号文章剪藏（保留 source/author） | `500-资源整合/530-优质文章剪藏` |
| 可复用代码片段、正则、工具函数 | `500-资源整合/510-代码片段` |
| 系统性技术学习沉淀（原理、体系化知识） | `300-学习笔记/` 对应技术栈子目录 |
| 具体问题复盘、踩坑记录 | 优先 `300-学习笔记` 对应技术栈；偏环境/安装的放 520 |
| 技术选型、架构想法、未落地的思考 | `400-想法随笔/410-技术思考` |
| 投资理财知识与策略 | `300-学习笔记/370-投资理财` |
| AI 编程工具、LLM API 相关 | `300-学习笔记/360-AI编程工具` |
| 装机、消费记录、日常生活 | `600-生活与娱乐/640-生活日常与消费` |
| 游戏攻略/评测、网文小说笔记、影音记录 | `600-生活与娱乐/620|630|610` |
| 按日期的零碎流水记录 | `100-每日笔记/YYYY-MM-DD.md` |

判断难点：**"操作指南" vs "知识笔记"**——拿来即用的安装/配置/工具操作进 500；讲清原理与体系的进 300。同一主题两边都可能存在（如 Maven 安装在 520，Spring 知识在 322）。
