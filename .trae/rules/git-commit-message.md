1. 提交信息格式：`[类型](模块)：[描述]`
   - 类型：`feat`、`fix`、`docs`、`refactor`、`test`、`chore` 等
   - 描述：对提交内容的简洁描述，避免使用复杂的术语或缩写
   - 示例：`:sparkles: feat: 新增登录功能`
   - 示例：`:bug: fix: 修复登录页面的错误提示`
2. 提交信息，需要添加 gitemoji 表情
   - 示例：`:sparkles: feat: 新增登录功能 :sparkles:`
   - 示例：`:bug: fix: 修复登录页面的错误提示 :bug:`
3. 提交信息，请采用中文描述
   - 示例：`:sparkles: feat: 新增登录功能`
   - 示例：`:bug: fix: 修复登录页面的错误提示`
4. 提交信息，标题与正文之间用空行隔开
   - 示例：`:sparkles: feat: 新增登录功能
   新增登录功能的实现
   - 示例：`:bug: fix: 修复登录页面的错误提示
   修复登录页面的错误提示的实现
