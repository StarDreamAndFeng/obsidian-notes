# Obsidian 文件命名注意事项

## 不要以点号 `.` 开头

**问题：** 如果笔记文件名以点号 `.` 开头（如 `.gitkeep 文件的作用.md`），Obsidian 会将其视为隐藏文件，不在文件列表中显示。

**原因：** 这是操作系统的约定——以点号开头的文件会被视为隐藏文件。Obsidian 遵循此约定，默认不显示隐藏文件。

**示例：**

```
❌ 错误：.gitkeep 文件的作用.md      ← 会被隐藏
✅ 正确：gitkeep 文件的作用.md       ← 正常显示
```

## 解决方案

### 方案一：重命名文件

去掉文件名开头的点号：

```bash
# 错误命名 → 正确命名
Rename-Item ".gitkeep 文件的作用.md" "gitkeep 文件的作用.md"
```

### 方案二：在标题中使用反引号

如果需要在标题中强调某个以点号开头的文件名（如 `.gitkeep`），可以在笔记内部标题中使用反引号包裹：

```markdown
# `.gitkeep` 文件的作用

这是笔记的正文内容...
```

## 其他命名建议

### 避免特殊字符

| 字符 | 建议 | 原因 |
|------|------|------|
| `/` | 避免 | 会被解析为目录分隔符 |
| `\` | 避免 | 会被解析为转义字符或路径分隔符 |
| `*` | 避免 | 会被解析为通配符 |
| `?` | 避免 | 会被解析为通配符 |
| `"` | 避免 | 会被解析为引号 |
| `<` `>` | 避免 | 会被解析为 HTML 标签 |

### 推荐命名风格

```
# 日期格式（用于日志、日记）
2026-07-25.md
2026-07-25-学习笔记.md

# 标题格式（用于主题笔记）
Git-gitkeep占位文件的作用.md
Obsidian-文件命名注意事项.md

# 简洁格式（用于日常笔记）
今日学习总结.md
项目进度记录.md
```

### 双向链接兼容

使用 Obsidian 双向链接时，文件名会作为链接目标：

```markdown
[[gitkeep 文件的作用]]     ← 链接到 gitkeep 文件的作用.md
[[Obsidian 文件命名注意事项]] ← 链接到 Obsidian 文件命名注意事项.md
```

确保文件名中不包含 `]]` 等特殊组合，以免影响链接解析。
