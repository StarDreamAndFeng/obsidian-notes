# AI 提示词工程指南

## 概述

提示词（Prompt）是与 AI 模型交互的指令或问题，良好的提示词设计能够显著提升 AI 输出的质量和准确性。提示词工程是一门将自然语言转化为有效指令的艺术与科学。

---

## 核心原则

### 原则一：明确具体

明确描述需求，避免模糊表述。

**反例：**

```
写一篇关于环保的文章。
```

**正例：**

```
写一篇 800 字左右的环保主题文章，重点讨论塑料污染对海洋生态的影响，要求逻辑清晰，包含具体数据和案例。
```

### 原则二：结构化输出

指定输出格式，便于后续处理。

**示例：**

```
请分析以下文本的情感倾向，输出格式为 JSON：
{"text": "文本内容", "sentiment": "positive|negative|neutral", "confidence": 0.0-1.0}

文本：今天的天气真不错！
```

### 原则三：提供上下文

必要时提供相关背景信息或示例。

**示例：**

```
作为一名专业的 Python 开发者，请帮我优化以下代码。代码功能是计算斐波那契数列前 100 项。

def fibonacci(n):
    result = []
    a, b = 0, 1
    for _ in range(n):
        result.append(a)
        a, b = b, a + b
    return result

print(fibonacci(100))
```

### 原则四：设定角色

为 AI 指定特定角色，以获得更专业的输出。

**示例：**

```
请以资深产品经理的角度，基于以下需求文档，设计一个电商购物车功能的原型方案。

需求：用户可以将商品加入购物车，修改数量，删除商品，查看总价。
```

### 原则五：分步骤思考

对于复杂任务，要求 AI 逐步推理。

**示例：**

```
请分步解决这个数学问题：一个水池有两个进水管和一个出水管。单独打开 A 管 6 小时可注满，单独打开 B 管 8 小时可注满，单独打开 C 管 12 小时可放空。三管同时打开，几小时可注满水池？

请按以下步骤回答：
1. 计算各水管的效率
2. 计算三管同时工作的净效率
3. 计算注满水池所需时间
```

## 常用技巧

### 技巧一：Few-Shot 学习

提供少量示例，让 AI 学习输出模式。

**示例：**

```
请将以下句子转换为被动语态。

示例：
主动：小明吃了苹果。
被动：苹果被小明吃了。

主动：老师批改了作业。
被动：
```

### 技巧二：Chain of Thought

引导 AI 展示推理过程。

**示例：**

```
请详细解释为什么天空是蓝色的。要求先给出结论，然后逐步解释原理，包括瑞利散射等概念。
```

### 技巧三：约束条件

设定明确的限制条件。

**示例：**

```
请用不超过 50 个字概括以下段落的主要内容。

段落：人工智能技术近年来发展迅速，在图像识别、自然语言处理、自动驾驶等领域取得了显著进展。
```

### 技巧四：输出格式控制

指定输出结构，如 Markdown、表格、JSON 等。

**示例：**

```
请对比以下三种编程语言的优缺点，输出格式为 Markdown 表格：

编程语言：Python、Java、Go

表格列：语言、优点、缺点、适用场景
```

## 进阶技巧

### 提示词模板

建立可复用的提示词模板，提高效率。

**通用模板结构：**

```
角色设定：[指定 AI 的角色]
任务描述：[详细描述要完成的任务]
输入数据：[提供必要的输入信息]
输出要求：[指定输出格式、长度、风格等]
约束条件：[设定限制条件]
示例：[提供参考示例，可选]
```

### 迭代优化

通过多次交互逐步优化提示词。

1. 初始提示词 → 获取输出
2. 分析输出缺陷 → 调整提示词
3. 重复上述步骤直至满意

### 提示词分层

将复杂任务分解为多个简单任务，分别设计提示词。

## 常见错误与避免

### 错误一：过于简略

**问题：** 需求描述不完整，导致 AI 猜测意图。

**避免：** 详细说明任务、约束条件和期望输出。

### 错误二：矛盾指令

**问题：** 在一个提示词中包含相互矛盾的要求。

**避免：** 检查提示词中的所有要求是否一致。

### 错误三：缺乏上下文

**问题：** 对于需要背景知识的任务，未提供足够信息。

**避免：** 在提示词中包含必要的背景信息或示例。

### 错误四：格式不清晰

**问题：** 提示词结构混乱，AI 难以理解。

**避免：** 使用清晰的标题、列表、分隔符等组织提示词。

---

## 总结

提示词工程的核心在于**清晰、具体、结构化**。通过遵循上述原则和技巧，可以有效提升与 AI 交互的效率和质量。持续实践和迭代是掌握提示词工程的关键。
