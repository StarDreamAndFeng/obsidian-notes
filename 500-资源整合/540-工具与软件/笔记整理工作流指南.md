# 笔记整理工作流指南

## 概述

当从外部来源（如 AI 对话、技术文章、代码片段）复制内容整理为笔记时，需要遵循一定的规范，确保笔记的专业性、通用性和可复用性。

---

## 核心原则

### 原则一：剔除口语化词汇

将对话式语言转换为书面语，提升笔记的专业性。

**常见需要剔除的词汇：**

| 口语化词汇 | 替换方式 |
|-----------|---------|
| 你、你好、请问 | 直接删除或改写为客观描述 |
| 我觉得、我认为 | 改为"建议"、"推荐"等 |
| 好的、没问题 | 删除 |
| 其实、然后、那么 | 删除或用更正式的连接词 |

**示例：**

原始内容：
```
你好，关于这个问题，我觉得可以用正则表达式来解决。你只需要匹配数字即可。
```

整理后：
```
可使用正则表达式匹配数字来解决此问题。
```

---

### 原则二：替换业务代码

将与特定业务场景相关的代码替换为通用示例，增强笔记的通用性和可复用性。

**示例：**

原始业务代码：
```javascript
// 库存出库计算
const pickingNum = Array.isArray(item.inventoryOutPicking)
  ? item.inventoryOutPicking.reduce((sum, p) => sum + (Number(p.num) || 0), 0)
  : 0;
```

替换为通用示例：
```javascript
// 数组求和（处理浮点数精度问题）
const nums = [0.1, 0.2, 0.3];
const sum = nums.reduce((acc, num) => acc + Math.round(num * 10), 0) / 10;
// 结果：0.6
```

---

### 原则三：结构化内容

使用 Markdown 语法组织内容，包括标题、列表、代码块等。

**推荐结构：**

```markdown
# 笔记标题

## 概述

## 核心内容

### 子标题

## 示例代码

## 注意事项

## 总结

---

**关联笔记：**
- [[相关笔记]]
```

---

### 原则四：添加元数据

为笔记添加 YAML frontmatter，包含标签和日期，便于搜索和分类。

**示例：**

```yaml
---
tags:
  - JavaScript
  - 浮点数
  - 精度问题
date: 2026-07-28
---
```

## 完整工作流

### 步骤一：复制原始内容

从外部来源复制需要整理的内容。

### 步骤二：初步筛选

删除无关内容，如问候语、闲聊、重复信息等。

### 步骤三：语言规范化

1. 剔除口语化词汇
2. 改写为正式书面语
3. 统一术语和格式

### 步骤四：代码通用化

1. 识别业务特定代码
2. 提取核心逻辑
3. 使用通用示例替换

### 步骤五：结构化组织

1. 添加标题和子标题
2. 使用列表和表格
3. 添加代码块和注释

### 步骤六：补充元数据

1. 添加 YAML frontmatter
2. 添加标签
3. 添加关联笔记链接

### 步骤七：校对检查

1. 检查是否还有遗漏的口语化词汇
2. 验证代码示例是否正确
3. 确保格式规范统一
