# Obsidian 编辑与阅读模式

Obsidian 允许你使用**视图**和**模式**来控制如何阅读和编辑以 Markdown 编写的笔记。

- **视图**：用于在阅读和编辑笔记之间切换
- **模式**：控制编辑时 Markdown 的显示方式

## 默认设置

> 默认情况下，Obsidian **以编辑模式**打开新标签页。
>
> 可以在 **设置 → 编辑器 → 新标签页的默认视图** 中更改此设置。

## 视图切换

### 快捷键

| 操作 | Windows/Linux | macOS |
|------|---------------|-------|
| 切换编辑/阅读视图 | `Ctrl + E` | `Cmd + E` |

### 其他切换方式

1. 点击编辑器右上角的视图切换器图标
2. 点击状态栏中的交互式状态图标，然后选择对应视图
3. 使用命令面板：`切换编辑/预览视图`

### 并排查看

按住 `Ctrl`（macOS 上为 `Cmd`）并点击视图切换器，可以**同时以编辑模式和阅读视图打开一篇笔记**（左右分屏）。

## 阅读视图

**阅读视图**不显示 Markdown 语法，提供干净、易读的格式，便于专注审阅。

适用场景：
- 阅读和复习笔记
- 查看格式化后的效果
- 专注内容本身

## 编辑模式

**编辑模式**允许你对笔记进行更改。编辑模式下有两种显示方式：

### 1. 实时预览（默认）

**实时预览**在行内显示格式化文本，同时隐藏大部分 Markdown 语法。当光标进入格式化内容时，底层语法会变为可见以便编辑。

> 默认编辑模式为**实时预览**。可在 **设置 → 编辑器 → 默认编辑模式** 中更改。

在许多情况下，实时预览可以消除切换到阅读视图的需要。

### 2. 源码模式

**源码模式**完全按照原样显示所有 Markdown 语法。适合偏好纯文本或需要精确格式控制的场景。

切换到源码模式：
- 点击状态栏中的交互式状态图标，选择「源码模式」
- 或在 `设置 → 编辑器 → 默认编辑模式` 中设置为默认

### 切换编辑模式

要在**实时预览**和**源码模式**之间快速切换，可以为命令「切换实时阅览/源码模式」设置一个快捷键。

## 模式关系图

```
Obsidian 视图
├── 阅读视图（只读，格式化显示）
└── 编辑模式（可编辑）
    ├── 实时预览（默认，行内格式化）
    └── 源码模式（纯 Markdown 显示）
```

## 常见问题

### Q: 为什么我打开文件默认是阅读模式？

A: 默认应该是编辑模式。如果你的 Obsidian 打开文件默认是阅读模式，可以检查：

1. 打开 **设置 → 编辑器 → 新标签页的默认视图**
2. 确认选择的是「编辑模式」而非「阅读视图」

### Q: 实时预览和阅读视图有什么区别？

A:
- **实时预览**：在编辑模式下，大部分 Markdown 语法被隐藏，光标移动到对应位置时才显示语法
- **阅读视图**：完全不显示 Markdown 语法，是只读模式，不能编辑

### Q: 如何快速在源码模式和实时预览之间切换？

A: 可以在 **设置 → 快捷键** 中为「切换实时阅览/源码模式」设置自定义快捷键。
