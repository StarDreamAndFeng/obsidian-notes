# Windows 更新失败 0x80073712 解决方法

## 一、问题现象

![Windows 更新失败截图](/000-仓库管理/020-附件与资源/windows_update_fail_0x80073712.png)

**错误代码**：`0x80073712`

**官方提示**：某些更新文件缺失或出现问题，我们将尝试稍后重新下载更新。

**典型表现**：下载进度条一直卡在 **6%**，随后直接跳转"安装中…"失败。

---

## 二、根本原因

`0x80073712` 通常表示 **Windows Update 缓存损坏** 或 **组件存储不一致**，常见于：

- 上一次更新非正常关机导致下载文件不完整
- `C:\Windows\SoftwareDistribution` 文件夹内的元数据或下载包损坏
- 系统长时间未重启，缓存堆积

> ⚠️ 此错误代码本身不指向某个具体 KB 补丁，而是「下载/安装组件存储」层面的问题。

---

## 三、解决方法

### 步骤 1：打开「服务」管理控制台

按住 `Win + R` 打开「运行」，输入：

```powershell
services.msc
```

按回车，打开本地服务列表。

### 步骤 2：停止 Windows Update 服务

1. 在服务列表中找到 **Windows Update**
2. 双击打开属性
3. 单击「**停止**」
4. 将「启动类型」改为「**手动**」
5. 确定保存

> 为什么要手动而不是自动？修复过程中不要让 Windows 自动重启该服务，否则下面删除缓存会被它重建占用。

### 步骤 3：清空更新缓存文件夹

打开 `C:\Windows\SoftwareDistribution` 目录，**删除**以下两个文件夹：

| 文件夹 | 作用 |
| --- | --- |
| `DataStore` | 存放更新日志、历史记录等元数据 |
| `Download` | 存放已下载但未安装的更新包 |

> ⚠️ **不要删除 `SoftwareDistribution` 文件夹本身**，只删其下的 `DataStore` 和 `Download` 子目录。Windows Update 重启时会自动重建这两个子目录。

### 步骤 4：重启服务并重启电脑

1. 回到「服务」管理控制台
2. 找到 Windows Update，单击「**启动**」
3. 重启电脑

---

## 四、修复后验证

重启后系统会自动重新尝试 Windows Update：

- ✅ 进入「设置」→「Windows 更新」，点击「检查更新」
- ✅ 观察下载进度是否能突破 6%
- ✅ 若仍失败，再次执行上述步骤；连续 2-3 次后通常可解决

> 如果仍然报 `0x80073712`，可考虑运行系统内置修复命令：
>
> ```powershell
> DISM /Online /Cleanup-Image /RestoreHealth
> sfc /scannow
> ```
>
> 这两个命令检查系统镜像和系统文件完整性，需要 **5-30 分钟**。

---

## 五、常见误区

| 误区 | 解释 |
| --- | --- |
| 「重启电脑就能解决」 | 单纯重启不会清除损坏缓存，必须手动删除两个子目录 |
| 「删 SoftwareDistribution 整个文件夹」 | ❌ 不要这么做，可能引发其他系统问题 |
| 「改了启动类型为禁用」 | 应改为「手动」而非「禁用」，否则后续更新无法触发 |
| 「不重启服务就重启电脑」 | 删除缓存后不启动服务，电脑重启时系统会重新触发更新，可能再次卡死 |
