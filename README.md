# obsidian-notes

个人 Obsidian 知识库笔记仓库，集中存放日常学习、工作记录、想法随笔与资料整理。

## 特点

- **纯 Markdown 格式**：所有笔记采用标准 Markdown 编写，便于跨平台阅读与编辑
- **Obsidian 原生特性支持**：
  - 双向链接（`[[笔记名称]]`）
  - 内部引用
  - 标签管理（`#标签`）
- **版本控制**：通过 Git 追踪所有笔记版本，支持多设备同步、备份与历史回溯

## 内容结构

- `学习笔记/` - 技术学习、课程笔记
- `工作记录/` - 日常工作、项目文档
- `想法随笔/` - 思考、灵感记录
- `资料整理/` - 书籍摘要、文章收藏

## 注意

- `.obsidian/` 目录已被 `.gitignore` 忽略，Obsidian 配置（主题、插件、工作区布局）不会同步到仓库
- 仓库内容持续更新，仅作个人知识沉淀

## 使用

```bash
# 克隆仓库
git clone <repository-url>

# 在 Obsidian 中打开
# File → Open Vault → 选择仓库目录
```

欢迎参考学习！
